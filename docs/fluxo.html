1O caminho dos dados

Da Receita Federal até a tela do tablet, sem ninguém precisar baixar ou enviar arquivo.

Receita Federal

CNO · Cadastro Nacional de Obras

  • arquivo cno.zip (~340 MB)
  • atualizado todo dia
  • 3,7 milhões de obras do Brasil
→
GitHub Actions

Rotina “atualizar-obras”

  • roda todo dia às 6h17; carrega se a última carga tem 3+ dias
  • baixa, filtra o Pará, tira infraestrutura, estima a fase
  • se a Receita cair: usa o último arquivo guardado
→
Supabase

Banco de dados e login

  • 36,5 mil obras do PA · 5,2 mil empresas
  • encaminhamentos, andamento, anotações, minhas construtoras
  • regras: admin vê tudo, vendedor só as dele
⇄
Cloudflare

O site

  • radar-obras.samuel-d2e.workers.dev
  • Todas as obras · Minhas obras · Construtoras · Insights · Equipe
⇄
Equipe

Quem usa

  • Admins: veem tudo, encaminham, Insights
  • Vendedores: obras encaminhadas, andamento, anotações
  • tablet, celular ou computador
Obras no radar: ativas, iniciadas desde 2023, de qualquer tamanho, sem infraestrutura — hoje 4.485.
Fase da obra: estimada pela data de início + prazo típico do tipo e tamanho; recalculada todo dia ao abrir o site.
Próximo passo dos dados: telefone, e-mail e natureza jurídica das empresas pela consulta de CNPJ (CNPJá).

2Como uma mudança chega ao site

Tudo pelo chat: você pede, eu faço e testo, e a publicação é automática.

① Você pede aqui

Pelo tablet, no chat com o Claude: uma tela nova, um ajuste, uma correção.

→

② Claude escreve e testa

Num ambiente de testes: banco local com os dados reais do Pará e o site num navegador simulado (tablet e celular).

→

③ Envia ao GitHub

commit + push no repositório outvision, branch claude/saas-prospeccao-obras-3t30et.

→

④ Mudou o site → Cloudflare publica

Em ~1 minuto, sozinha. Você só recarrega a página.

④ Mudou o banco ou a carga → GitHub Actions

Aplica a estrutura nova no Supabase e recarrega as obras (~10 minutos).

GitHub

Código e todo o histórico de mudanças. Público por enquanto; fica privado quando estabilizar.

Supabase

Dados, logins, andamento e anotações. Nunca vão para o GitHub.

Cofre do GitHub

A senha do banco (SUPABASE_DB_URL), usada só pela rotina.

Cloudflare

As chaves públicas que ligam o site ao banco.
